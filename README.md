# Uber Booking Power BI Dashboard

An interactive Power BI dashboard designed to analyze Uber booking data and provide insights into bookings, revenue, ride distance, vehicle performance, payment methods, and customer behavior.

## 📊 Project Overview

This project uses Power BI to transform Uber booking data into an interactive and easy-to-understand business dashboard.

The dashboard helps analyze key business metrics and identify trends in bookings, revenue, vehicle performance, customer ratings, and ride status.

## 🛠️ Tools & Technologies

* **Power BI**
* **Power Query** – Data cleaning and transformation
* **DAX** – Calculated measures and KPIs
* **Microsoft Excel** – Data source and preparation

## 📌 Dashboard Pages

The dashboard contains 6 interactive pages:

1. **Home** – Overall dashboard summary
2. **Overview** – Booking and ride performance
3. **Vehicle** – Revenue and performance by vehicle type
4. **Revenue** – Revenue trends and payment analysis
5. **Rider** – Customer and ride analysis
6. **Bookings** – Booking status and detailed analysis

## 📈 Key KPIs

* Total Bookings
* Completed Bookings
* Total Revenue
* Total Ride Distance
* Average Driver Rating
* Average Customer Rating
* Cancelled Bookings
* Incomplete Bookings

## 🔍 Key Analysis

* Monthly booking and revenue trends
* Revenue by vehicle type
* Revenue by payment method
* Top pickup and drop locations
* Completed, cancelled and incomplete bookings
* Customer and driver ratings
* Ride distance analysis
